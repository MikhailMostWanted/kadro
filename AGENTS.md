# KADRO: инструкции для продолжения

Сначала прочитай README.md, docs/VALIDATION.md и docs/CODEX_HANDOFF.md.

Это локальный C++20/Qt Widgets просмотрщик фото и видео для Windows/macOS, не веб-приложение. Приоритет — быстрый первый кадр, удобное листание соседних файлов, минималистичный русский интерфейс и безопасность оригиналов. Не переписывай стек без согласования с владельцем.

Сборка: `cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON`, затем `cmake --build build` и `ctest --test-dir build --output-on-failure`. Без Qt доступна проверка ядра с `-DKADRO_BUILD_APP=OFF`.

Любое изменение файловых действий требует регрессионных тестов: нет перезаписи существующего файла при переименовании; корзина никогда не заменяется безвозвратным удалением; поворот не меняет исходник. Не обходить UserChoice, Gatekeeper и другие системные ограничения.

Не коммить секреты, пользовательские медиа, сборочные каталоги или сертификаты. Не применяй force push, не меняй приватность репозитория и не стирай чужие незакоммиченные изменения. Документация и итоговый отчёт — на русском. В отчёте отличай реально выполненные проверки от добавленных, но не запущенных тестов.
