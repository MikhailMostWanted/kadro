# Продолжение KADRO

## Задача

Михаил хочет быстрый локальный просмотрщик фото **и** видео для Mac/Windows: двойной щелчок → файл виден → стрелки листают соседей; фильтры Все/Фото/Видео; удобный показ в папке. Это не медиатека и не редактор. Никаких аккаунтов, серверов, AI-функций, веб-оболочки и импорта в библиотеку.

Уже написано C++20/Qt Widgets приложение, а не макет. Не начинать заново на Electron/Tauri/Python. Интерфейс и тексты русские, документация русская; логика разбита на модули. Не переносить сюда чужие проекты. Не добавлять «демонстрационные» счётчики или выдуманные замеры.

## Первый проход

1. Прочитать README и VALIDATION, проверить текущую ветку, git status и историю. Существующие изменения Михаила не стирать. Без force push и переписывания истории.
2. Воспроизвести полный build + ctest. Проверить запуск **установленной** папки `dist`, а не только binary из build с доступом к Qt разработчика.
3. На машине Михаила открыть JPEG/PNG/WebP/GIF, портретный HEIC с iPhone, MP4 H.264, MOV HEVC, MKV и повреждённые файлы. Отдельно записать контейнер и кодек: одно расширение не доказывает поддержку.
4. Пройти последовательность фото → видео → фото → видео; быстрые 100 нажатий; смена папки во время декодирования; закрытие во время загрузки; Unicode/пробелы/скобки в путях; второй экземпляр и Finder open-file.
5. Измерить холодный первый кадр, тёплое листание и память на **конкретных** компьютерах, с указанием разрешения файлов и размера папки. Предварительная цель — ощущение мгновенного открытия; числовой SLA пока не утверждён и не измерен.

## Приоритеты исправлений и полировки

- Проверить пиктограммы/типографику, кликабельные зоны, длинные имена, ширину окна 820–1200, масштаб Windows 100/150/200%, Retina, светлую тему. Не превращать интерфейс в панель управления. Сделать адаптивную компактную нижнюю панель при узком окне.
- HEIC на Windows: нативный WIC fallback зависит от установленного кодека. Перед выпуском исправить/подтвердить ориентацию всех 8 EXIF-положений, цветовые профили и SDR-представление HEIC. Нужны реальные файлы, не только фикстура. При необходимости добавить модуль libheif с явно проверенной сборкой/лицензированием; не скачивать произвольные кодеки пользователю.
- GIF/WebP-анимации используют QMovie, декодирование кадров может нагружать GUI. Прогнать тяжёлые анимации, ошибки чтения и отображение первого кадра. Не кешировать бесконечную анимацию целиком.
- Проверить нагрузку сортировки proxy на GUI для 10 000–100 000 имён. Сканирование уже фоновое, но proxy-сортировка/статистика файлов в кеше требуют измерения. При реальной задержке перенести расчёты в worker, не добавляя базы данных.
- Сделать настоящие постеры видео в миниатюрах: ленивый worker, ограничение параллелизма и памяти, отмена устаревших заданий, без запуска decoder на каждый файл папки сразу.
- Проверить видеопозиции при долгой загрузке метаданных, окончании видео, паузе и ошибках; затем добавить настройку автозапуска/запоминания. Привязка громкости/позиции уже есть.
- Автоскрытие панелей по бездействию в полноэкранном режиме, плавное появление при движении мыши; не прятать элементы при перемотке/открытом меню. Сейчас есть явное скрытие Tab.
- Полноценный Windows installer и Mac DMG, иконка файлов, безопасное удаление только собственных регистраций. Сейчас есть portable/app пакеты и явная регистрация Windows через меню.
- Подпись/Apple notarization, точный inventory зависимостей и включение применимых licenses/notices. Не считать публичный релиз готовым до этого. Сертификаты/ключи не коммитить и не просить вставлять в чат.

## Не сломать

Оригиналы не перезаписываются поворотом/масштабом. Корзина не заменяется unlink/remove при ошибке. Переименование не перезаписывает существующий файл. Default-app `UserChoice` не модифицируется. Локальный IPC ограничен текущим пользователем и 64 КиБ. Сетевая телеметрия/обновлятор не добавляются. Нет автоматического открытия последнего приватного фото при запуске.

После проверки оставь короткий отчёт: что исправил, что реально проверил и что осталось».
