# Установка Wanted View 0.1.1 RC

Эти сборки предназначены для приёмки. Приложение в DMG запечатано подписью ad hoc. Для внешней поставки требуются Apple Developer ID и нотариальное заверение. У Windows Setup нет подписи Authenticode. Сверьте SHA-256 пакета с отчётом о сборке.

## macOS

1. Откройте `WantedView-macOS-universal-RC.dmg`. Скопируйте `Kadro.app` в «Программы» и извлеките диск.
2. Запустите Wanted View из «Программ». Нажмите «Открыть» или перетащите файл в окно. Чтобы проверить просмотрщик по умолчанию, выберите его сами в свойствах тестового файла Finder.
3. Для удаления закройте приложение и перенесите установленную копию `Kadro.app` в корзину. Если назначали его приложением по умолчанию, выберите другой просмотрщик в свойствах нужных типов файлов. Настройки Qt сохраняются при замене приложения, как и идентификатор пакета `app.kadro.viewer`.

## Windows x64

1. Запустите `WantedView-Windows-x64-RC.exe`. Установка для текущего пользователя, по умолчанию в `%LOCALAPPDATA%\Programs\Kadro`. Откройте Wanted View из меню «Пуск».
2. При необходимости откройте меню действий в Wanted View и выберите «Приложение по умолчанию…». Программа появится в списке Windows. Форматы назначаются вручную в параметрах Windows. Для HEIC может понадобиться установленный в системе кодек HEIF/HEVC.
3. Для удаления сначала смените просмотрщик по умолчанию, если назначали Wanted View. Затем откройте «Параметры → Приложения → Установленные приложения → Wanted View → Удалить». Установщик снимает регистрацию только своего экземпляра. Фото, видео и пользовательские настройки сохраняются.

Portable-версию распакуйте целиком и запустите `bin\Kadro.exe`. Если будете пользоваться ею без установщика, оставьте ассоциации файлов прежними. Для удаления portable-версии уберите распакованную папку, предварительно перенеся свои файлы из неё.

## Возврат к предыдущей сборке

Закройте Wanted View. На macOS замените `Kadro.app` копией из предыдущего проверенного DMG. На Windows удалите текущий кандидат через его деинсталлятор и установите прежний Setup в ту же папку. Если вы пользовались ассоциациями Wanted View, после отката снова проверьте выбранные приложения в Finder или Windows. Обе версии используют те же имена профиля Qt и системных регистраций.

## Корзина и исходные файлы

В меню действий (F10) выберите «В корзину…». Сверьте имя и подтвердите кнопкой «В корзину» или нажмите «Отмена». После переноса откройте системную корзину и выберите «Вернуть» на Mac или «Восстановить» в Windows. Если система не может принять файл, Wanted View покажет ошибку. Операции «Удалить навсегда» в приложении нет. Поворот и масштаб меняют только отображение.

## Диагностика

`--isolated` и `--smoke-screenshot` запускают отдельный процесс с временными настройками. Для повторного запуска с теми же настройками передайте `--settings-dir` с абсолютным путём к отдельной папке. С ней приложение использует INI-профиль и обходит обычный канал открытия файлов уже запущенным экземпляром. Передавайте разные папки параллельным диагностическим запускам. Профиль может содержать путь к последней папке. Держите его у себя или используйте тестовые файлы.
