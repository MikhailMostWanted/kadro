# Источники снимков KADRO

Три неизменённых снимка настоящего нативного окна macOS, снятые во время этого прохода. Это установленный локальный `.app` с Qt6.8.3, source/runtime `e1c11fec74b79d66def1ed88976d71c34d831aca`, arm64/macOS26.6.2. Окно запускалось с явным собственным `--settings-dir`; медиа — геометрические изображения и H264/AAC testsrc2/sine, целиком созданные для задания. Пользовательских фотографий, референсов или сторонних сцен нет; PNG не ретушировались.

`macos-photo.png` — стартовый PNG; `macos-view-rotation.png` — поворот вида без изменения файла; `macos-video.png` — кадр движущегося видео. В исходном evidence соседние кадры11 и12 различаются; видео не выводится как статичный постер. Снимки Qt offscreen/QVideoSink не подменяют эти нативные снимки.

Это не подтверждение слышимости аудио, аппаратного декодирования, чистой ОС без SDK, IntelMac или Windows. Контролируемое восстановление5000мс отдельно подтверждено Qt-регрессией на собственном12-секундном AVI; нативный reopen наблюдался после нескольких секунд автопроигрывания.

Два неожиданных повторных запуска средством наблюдения без исходных аргументов остановлены; их результат не принят как изолированная приёмка. Возможное чтение обычных настроек и неизвестность записи раскрыты в журнале текущего прохода. Сохранность пользовательских настроек не заявляется.
